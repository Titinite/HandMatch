# ADR-0009 : Pas de messagerie interne pendant la bêta

- **Statut** : Acceptée
- **Date** : Décision prise en phase de conception, consignée le 2026-11-27
- **Tickets** : HM-47, HM-153

## Contexte

Une messagerie interne exige une modération à grande échelle et un traitement spécifique des échanges avec des mineurs. La modération repose sur un seul modérateur.

## Décision

Pas de messagerie interne pendant la bêta. Les clubs contactent les personnes via les coordonnées affichées sur le profil ; pour un joueur mineur, le contact passe par l'email ou le téléphone du parent, accessible depuis le profil du mineur.

## Alternatives envisagées

- Messagerie interne modérée : meilleure expérience, mais charge de modération et risque juridique disproportionnés pour une bêta.

## Conséquences

- Il faut afficher et protéger les coordonnées (téléphone partiellement masqué, parent pour les mineurs).
- Le signalement d'un profil ou d'une offre reste le principal outil de modération.
- La question est rouverte au bilan de la bêta (HM-153).
